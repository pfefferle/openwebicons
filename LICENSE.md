# License

OpenWeb Icons is two things in one repository, and they carry different licenses.

## The font and the icons

The SVG artwork in `svg/` and `composed/`, the webfont in `font/` built from it, and the CSS and SCSS that load the font are released under the [SIL Open Font License 1.1](LICENSE-OFL.txt), with Reserved Font Name "OpenWeb Icons".

This is what the npm package and the Composer component ship.

## The WordPress plugin

The plugin code, `openwebicons.php` and `readme.txt`, is released under the [GNU General Public License v2 or later](LICENSE-GPL.txt).

The plugin bundles the SVG artwork, so the plugin zip contains both license files.
